# Getting Started with Northwind Cloud

This guide walks new teams through their first day on Northwind Cloud.

## Create your organisation

Sign up with a work email address and verify it. The first user becomes the organisation owner. Owners can invite teammates from Settings > Members and assign one of three roles: Owner, Developer or Billing Viewer.

## Free trial

Every new organisation starts with a 30-day free trial of the Business plan, including $200 of usage credit. No credit card is needed to start the trial. When the trial ends, the organisation moves to the Free plan unless a payment method has been added.

## Your first project

Projects group resources, API tokens and billing alerts. Create a project, pick a region close to your users, and deploy a starter template from the console or with the northwind CLI by running `northwind init`.

## Install the CLI

The northwind CLI is available for macOS, Linux and Windows. Install it with Homebrew, the official install script, or by downloading a binary from the releases page. Run `northwind login` to connect it to your account.

## Set up billing alerts

We recommend creating a billing alert during onboarding. Alerts can notify you by email or webhook when projected monthly spend crosses a threshold you choose.
